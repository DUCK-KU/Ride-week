# Ride Week

개인용 라이딩 기록 웹 앱입니다.

- 라이딩 기록 추가·수정·삭제
- 실외·실내 필터와 지표별 표시 전환을 지원하는 8주 훈련 추이
- 선수 데이터(FTP·최대 심박·LT1 심박/파워·LT2 심박/파워·FatMax·VO2max) 일괄 설정
- FTP 기준 NP·IF·TSS 계산
- 주간·월간 Z1~Z7 파워존 단일 누적 막대와 존별 비율·시간
- 시작 시각·강풍·그란폰도 제목 기준 라이딩 아이콘 자동 설정
- 그룹 라이딩 아이콘과 기간별 라이딩 기록 찾기
- 파워·케이던스·심박·고도 통합 그래프와 항목별 표시 전환
- 개별 라이딩 연도·실내외 구분, 주요 기록 카드, 최대 심박, 비율 중심 파워존·심박존
- 횟수·훈련량·TSS가 포함된 주간 추이와 주별 라이딩 요약
- 월요일–일요일 기준 주간 집계
- 종목 필터 뒤에도 다음 페이지를 계속 조회하는 Strava 전체 활동 동기화
- 목표 설정 및 백업/복원

라이딩 기록은 브라우저의 로컬 저장소에만 보관됩니다.
