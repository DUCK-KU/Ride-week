# Ride Week

개인용 라이딩 기록 웹 앱입니다.

- 라이딩 기록 추가·수정·삭제
- 실외·실내 필터와 지표별 표시 전환을 지원하는 8주 훈련 추이
- 선수 데이터(FTP·최대 심박·LT1 심박/파워·LT2 심박/파워·FatMax·VO2max) 일괄 설정
- 홈 목표 아래 FTP·최대심박·VO₂max 상태 요약
- 플레이어 신장·몸무게 설정 및 FTP W/kg·등급 표시
- 라이딩 합계를 종합·실외·실내로 전환
- 개인정보를 제외한 최근 2주 상세·6주 추세 코치용 JSON 내보내기
- Strava 센서 요약값(평균 파워·심박·최대심박·케이던스) 영구 저장
- 기존 기록 이후의 새 라이딩만 확인하는 증분 동기화 및 6시간 주기 앱 실행 시 자동 확인
- 새 기기용 전체 동기화와 빠른 새 기록 가져오기 버튼 분리
- 동일 동기화 키를 사용하는 기기 간 목표·플레이어 데이터 자동 동기화
- 기간 기록 종합·실외·실내 필터와 기간 심박존 분포
- 최근 90일 Strava 자동값과 수동값의 오차를 보여주는 1초~60분 파워 프로필·파워 커브
- FTP 기준 NP·IF·TSS 계산
- 주간·월간 Z1~Z7 파워존 단일 누적 막대와 존별 비율·시간
- 시작 시각·강풍·그란폰도 제목 기준 라이딩 아이콘 자동 설정
- 두 사람 형태의 선형 그룹 라이딩 아이콘과 달력 기반 기간별 기록 찾기
- 선택 기간의 횟수·훈련시간·거리·상승고도 합계
- 연도·월 바로가기와 월간·연간 데이터 보기
- 파워·케이던스·심박·고도 통합 그래프와 항목별 표시 전환
- 개별 라이딩 연도·실내외 구분, 주요 기록 카드, 최대 심박, 비율 중심 파워존·심박존
- 횟수·훈련량·TSS가 포함된 주간 추이와 주별 라이딩 요약
- 월요일–일요일 기준 주간 집계
- 종목 필터 뒤에도 다음 페이지를 계속 조회하는 Strava 전체 활동 동기화
- 주간·월간·연간 거리 목표 설정 및 백업/복원

라이딩 기록은 브라우저의 로컬 저장소에만 보관됩니다.
